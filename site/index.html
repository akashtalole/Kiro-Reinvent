Your first spec-driven change from the terminal

  1. Install the Kiro CLI and sign in.
  2. Ground it: generate steering files that describe your product, stack and structure.
  3. Plan with the plan agent, then let Kiro implement and verify.
Open Lab 01 → 
# 1 · install (macOS / Linux)
$ curl -fsSL https://cli.kiro.dev/install | bash
$ kiro-cli login

# 2 · open your project and chat
$ cd my-service && kiro-cli
> Generate steering docs for this repo
> /plan Add rate limiting to the public API

# 3 · or run it headless in CI
$ kiro-cli chat --no-interactive \
    --trust-tools=read,grep "Review this diff for risky changes"
