AI-first SaaS on AWS — build and operate with Kiro

Flow

  1. 1Each persona works through its Kiro agent and skills; requests become EARS specs.
  2. 2Kiro implements spec tasks and opens pull requests (Implements: spec#task).
  3. 3CI runs the spec gate, tenant-isolation tests, AI tenancy review and AI cost diff; humans merge.
  4. 4Only merged changes deploy, via CDK to CloudFormation, with an OIDC role.
  5. 5CloudFormation updates the multi-tenant workload.
  6. 6Per-tenant metrics, agent traces and online evaluations land in CloudWatch Omni.
