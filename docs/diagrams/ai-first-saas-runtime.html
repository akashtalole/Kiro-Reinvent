AI-first SaaS on AWS — multi-tenant runtime with AI features

Flow

  1. 1Tenant users call the product over HTTPS through CloudFront.
  2. 2CloudFront forwards API calls to API Gateway.
  3. 3Requests reach tenant services with tenant context from the authorizer, never from the body.
  4. 4Tenant data in a pooled table, isolated by TENANT#id keys and IAM LeadingKeys conditions.
  5. 5AI features invoke a Strands agent on AgentCore Runtime with the tenant's identity.
  6. 6Prompts and responses pass Bedrock Guardrails (prompt-attack and PII filters).
  7. 7Model calls use the tenant's application inference profile for per-tenant cost and quotas.
  8. 8Retrieval always filters on tenantId metadata.
  9. 9Tools are reached only through AgentCore Gateway, where Cedar policy checks tool, arguments and tenant claim.
  10. 10Permitted tool calls run in tenant tool Lambdas.
