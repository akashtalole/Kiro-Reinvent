# 10-foot UI checklist (Fire TV)

- [ ] Every interactive element is reachable with up/down/left/right; no focus traps or dead ends
- [ ] Initial focus lands on the primary action on every screen
- [ ] Focus is always visible (scale, outline or colour change), including on images
- [ ] Back returns to the previous screen and never exits the app unexpectedly from a sub-screen
- [ ] Body text is large enough to read from a sofa; nothing important is smaller than the guidance in Amazon's design docs
- [ ] Contrast is high; no information conveyed by colour alone
- [ ] Content stays inside the TV-safe area (no clipping at the edges)
- [ ] Long lists remember position when you come back
- [ ] Loading and error states are visible and focusable (a retry button, not a dead screen)
- [ ] The app works with only the remote — no pointer or keyboard required
