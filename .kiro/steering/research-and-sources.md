# Researching facts

1. Prefer, in order: official docs (kiro.dev/docs, docs.aws.amazon.com, strandsagents.com), the product's source code (for open-source tools like Kiro Crew), the AWS Knowledge MCP server, official blogs. Third-party posts only as secondary, and say so.
2. Quote short phrases and link the exact page. Record the page's "updated" date when it has one.
3. Mark Preview / Feature Preview features explicitly.
4. For prices, use the AWS Pricing MCP server or archify-aws `cost`; never compute prices by hand. Label estimates as indicative list prices.
5. When two sources disagree (docs vs blog), follow the docs and mention the discrepancy.
